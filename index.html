LightXAI-WaveNet: Explainable Hybrid Deep Learning Framework

Developed LightXAI-WaveNet, an explainable hybrid deep learning framework for early lung nodule classification, as part of a faculty-initiated research project supervised by Dr. Misni, Ph.D. (Kyushu University, Japan). The system integrates Discrete Wavelet Transform (DWT), Adaptive Singular Value Decomposition (SVD), 3D Convolutional Neural Network (CNN), and Vision Transformer (ViT) with Cross-Attention fusion to classify lung nodules into 5 classes (C0–C4): Normal, Tiny Benign, Tiny Malignant, Large Benign, and Large Malignant.

Key Contributions:

  • Designed and implemented hybrid pipeline using DWT + SVD for multi-resolution feature extraction and dimensionality reduction.
  • Developed 3D CNN + Vision Transformer (ViT) with Cross-Attention fusion for local-global feature learning.
  • Achieved Best AUC 0.8068 and Test Macro AUC 0.7968 on LIDC-IDRI dataset (887 samples).
  • Conducted Ablation Study (M1–M5) proving DWT (+2.89%) and Cross-Attention (+45.8%) effectiveness.
  • Implemented Explainable AI (XAI) using Grad-CAM 3D for visual interpretation of model focus areas.
  • Developed IoU (Intersection over Union) evaluation module to compare model predictions with radiologist annotations.
  • Built an interactive Streamlit GUI with real-time detection, Grad-CAM visualization, 8 subband 3D-DWT, and IoU analysis.
  • Deployed GUI on Streamlit Cloud for accessible demonstration.
  • Integrated histogram-based intensity analysis and ensemble voting for robust decision support.
Interactive GUI: lightxai-wavenet-gui.streamlit.app
